# 하우스푸어 🏢

픽셀 도트 감성의 **내 집 마련 가계부 PWA**. PC·모바일에서 같은 주소로 쓰고, 홈 화면에 설치하면 앱처럼 오프라인으로 동작합니다. 둘이서 같은 저장소에 연결하면 가계부가 합쳐집니다.

## 기능

| 영역 | 내용 |
|---|---|
| 홈 | 목표 건물 픽셀 일러스트(진척도만큼 아래층부터 불이 켜짐), 진행률, **앞으로 n개월/n주/n일 더 모으면 입주 가능** 카운트다운 |
| 목표 | 1~3위 등록 · 이름/금액/지역/평형 · **건물 형태 6종**(고층·복도식·저층 아파트, 빌라, 단독주택, 오피스텔) · 층수 · 색상 |
| 대출 | **정책 상품 프리셋**(보금자리론·디딤돌·신생아 특례·생애최초·일반) · LTV/DSR/상품한도 중 최솟값 · 자격 요건 경고 |
| 달력 | 월별 그리드에 일 지출(-)·수입(+), 저축일 파란 점, **무지출 날 👍 아이콘**, 날짜 클릭 시 상세 |
| 통계 | 일/주/월 지출·저축 추이, 기간 합계, 저축률, 카테고리별 지출, **멤버별 지출** |
| 가계부 | 지출/수입/저축 3종, 20개 카테고리(도트 아이콘), 빠른 금액 버튼, 메모, 수정/삭제, 월 예산 게이지 |
| 공유 | **최대 2명** 등록 · 내역마다 작성자 기록 · GitHub 비공개 저장소를 통한 양방향 동기화 |
| 기타 | 낮/밤 테마, JSON 백업 내보내기·불러오기, 전체 초기화 |

## 계산 방식

```
모은 돈      = 시드머니 + 저축 기록 + 남은 현금(수입-지출-저축, 양수일 때)   ← 중복 집계 방지
대출 한도    = min( 집값 × LTV ,  (연소득 × DSR ÷ 12) ÷ 월상환계수 ,  상품 한도 )
필요 총액    = 집값 × (1 + 부대비용%)
필요 자기자본 = 필요 총액 - 대출 한도
남은 기간    = (필요 자기자본 - 모은 돈) ÷ 월 저축 속도
```

월 저축 속도는 **최근 90일 기록**으로 자동 추정하며, 설정에서 직접 입력하면 그 값이 우선합니다.
정책자금은 DSR 대신 자체 한도·요건이 적용되므로 `DSR 0%`로 두고 상품 한도만 겁니다.

> ⚠️ **정책자금 조건은 공고에 따라 수시로 바뀝니다.** 프리셋은 출발점일 뿐이며, 실제 공고 기준으로 설정에서 직접 조정해서 쓰세요. 규제지역·다주택·스트레스 DSR 등은 반영돼 있지 않습니다. 모든 수치는 참고용 추정치입니다.

## 두 사람이 같이 쓰기

정적 사이트라 서버가 없습니다. 대신 **본인 소유의 비공개 GitHub 저장소에 있는 JSON 파일 하나**를 공용 저장소로 씁니다.

1. 비공개 저장소를 하나 만듭니다 (예: `내아이디/housepoor-data`)
2. [fine-grained 액세스 토큰](https://github.com/settings/personal-access-tokens/new)을 발급합니다
   - Repository access: **그 저장소 하나만** 선택
   - Permissions → Repository permissions → **Contents: Read and write**
3. 앱 → 설정 → GitHub 동기화에 `저장소 / 경로 / 토큰` 입력 → **연결 확인** → **지금 동기화**
4. 상대방 기기에서도 **같은 저장소·같은 토큰**을 입력하고, 설정 → 함께 쓰는 사람에서 본인을 지정합니다

동기화는 `받기 → 병합 → 올리기` 순서로 동작합니다. 내역·목표는 `id` 기준으로 합치고 **더 최근에 수정된 쪽**이 이깁니다. 삭제는 묘비(tombstone)로 기록돼 다른 기기에서 되살아나지 않습니다. 앱을 다시 열거나 내역을 저장하면 자동으로 동기화됩니다.

> 🔐 **토큰은 이 기기의 브라우저(localStorage)에 평문으로 저장됩니다.** 반드시 비공개 저장소 하나에만 권한을 준 fine-grained 토큰을 쓰고, 공용 PC에서는 사용하지 마세요. 토큰이 노출되면 GitHub 설정에서 즉시 폐기(revoke)하면 됩니다.

## 실행

PWA는 `http(s)` 환경에서만 서비스워커가 동작합니다. `index.html`을 더블클릭(`file://`)하면 화면은 보이지만 **설치·오프라인은 안 됩니다.**

```bash
python -m http.server 8777     # http://127.0.0.1:8777
```
`localhost`는 보안 컨텍스트로 취급되어 설치까지 테스트할 수 있습니다.

### 배포 (GitHub Pages)
빌드 과정이 없어 폴더를 그대로 올리면 끝입니다.
`Settings → Pages → Source: Deploy from a branch → main / (root) → Save`

설치: **Android/Chrome** 메뉴 → "앱 설치" · **iOS/Safari** 공유 → "홈 화면에 추가" · **PC Chrome/Edge** 주소창 설치 아이콘

## 구조

```
index.html              화면 뼈대
manifest.webmanifest    PWA 매니페스트
sw.js                   서비스워커 (HTML 네트워크 우선 / 에셋·CDN 폰트 캐시 우선)
css/style.css           픽셀 디자인 토큰 + 레이아웃 (모바일 탭바 / 900px↑ 사이드레일)
js/sprites.js           16×16 도트 스프라이트 24종
js/pixel.js             건물 렌더러 — 형태 6종, 컨테이너 비율에 맞춰 가로 도트 수를 계산해 배경을 꽉 채움
js/store.js             데이터 모델·카테고리·대출 상품·멤버·동기화 병합
js/calc.js              금액 포맷(억/만), 집계, 대출·기간 계산
js/sync.js              GitHub Contents API 동기화
js/ui.js                화면 5종 + 입력 시트
js/app.js               이벤트 위임, 백업, 테마, SW 등록
fonts/                  Galmuri11 (SIL OFL) — 없으면 jsDelivr로 폴백
icons/                  SVG + PNG 앱 아이콘
```

데이터는 브라우저 `localStorage`(키 `phb.v1`)에 저장됩니다. 동기화를 쓰지 않는다면 **설정 → 백업 내보내기**로 따로 보관하세요.
